# João Gomes — Portfolio

Personal portfolio website showcasing my work and skills across Marketing, Design and Web Development. Built with plain HTML, CSS and JavaScript, and hosted on GitHub Pages.

**Live site: [joaogomes.online](https://joaogomes.online)**

## About

I have experience across three key areas of any modern business: **Marketing, Design and Web**. I plan and structure websites, design every part of them, translate designs into code, optimize for SEO, and put together reports on performance and audience statistics.

- **Marketing** — content planning, branding, strategy, SEO optimization, usage tracking and conversion rate optimization.
- **Design** — strong sense of UI/UX, with experience in Figma, Canva and the Apple creative suite (Pixelmator, Final Cut, etc.).
- **Code** — HTML, CSS, JavaScript and PHP, including PHP development for WordPress.

## Tech Stack

- **HTML, CSS & JavaScript** — core of the site
- **[Lenis](https://lenis.darkroom.engineering/)** — smooth scrolling
- **[Animate.css](https://animate.style/)** — scroll/entry animations
- **[Bootstrap Icons](https://icons.getbootstrap.com/)** — iconography
- Custom reusable header components (`template-parts/header.js`, `template-parts/headermobile.js`) loaded via custom elements (`<my-header>`, `<my-header-mobile>`)

Additional skills applied to client project work (not necessarily used on this site itself): **PHP** and **WordPress** development.


## Deployment

The site is deployed via **GitHub Pages**. Any push to the main branch (or the branch configured under **Settings → Pages**) updates the live site automatically.
